## [1.0.0] – 2024-06-28

### Added
- 🎉 Initial production release
- Home page with GSAP scroll animations, hero, trust section, FAQ
- 7 course pages with dynamic routing (`/courses/[slug]`)
- Course listing page with search & category filter
- Interactive gallery — CSS masonry, lightbox with keyboard nav
- Testimonials page — Tamil/English reviews, initials avatars
- About page with owner biography in Tamil & English
- Blog section with 2 articles
- Contact page with WhatsApp & Google Maps
- Smooth Lenis scrolling throughout
- Animated scroll-to-top button (bottom-right)
- WhatsApp floating button with tooltip
- Exit intent popup
- SEO: JSON-LD schema, sitemap.xml, robots.txt, Open Graph
- Lifetime Teaching Support FAQ entry
- Mobile-responsive sidebar drawer navigation
- All 20 static pages pre-rendered (SSG)

### Tech Stack
- Next.js 16.2.6, React 19, TypeScript 5
- Tailwind CSS v4, GSAP 3.15, Framer Motion 12
- Lucide React icons, Lenis smooth scroll
